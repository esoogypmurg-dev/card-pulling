📢 App update notice

Players see a popup when they log in (or if already online, after you publish) if they haven’t dismissed this version yet.

🔄 Force refresh

Pushes a non-dismissible popup to every player currently online, forcing them to reload the page. Use this right after deploying a breaking change.

⚡ Live flash (online only)

Pops up instantly for players who are online right now. Does not wait for offline users. Auto-hides after 5 seconds.

⏳ Home countdown banner

Create a banner that appears at the top of Home with a live countdown. Publish it to make the same banner appear for every player.

How it works

Set the date/time you want the countdown to reach zero. The banner updates every second for players, and the optional end date hides it afterward.

🗂 Sets visibility

Hidden sets are invisible to players — no Shop pack option, no Open Packs tab, no Collection tab, no binder shelf entry. Toggle a set visible when you're ready to launch it.

🏅 Achievements

Create achievements for players. Use series + tier for progressive chains (e.g. Pull 5 → Pull 10). Optional set filter and card rewards supported.

⚡ Generate for a set

One click creates the standard "Set Master" + per-rarity achievements for a set, using its real card counts from Supabase. Safe to click again after adding more cards — it only fills in what's missing.
